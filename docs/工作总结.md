## 2026-07-26 · 桌面壳 Tauri → Wails 切换

### 切换动机
- **Tauri 卡点**：MSVC `link.exe` 不在 PATH，rustup 默认 GNU 工具链缺 dlltool/MinGW 库；VS Build Tools 静默安装需 5GB+ 磁盘与长时间等待
- **Wails 优势**：Go 工具链单一，无 C 工具链依赖，复用现有 Go 1.26 环境
- **命门验证**：`wails doctor` GREEN，未要求 gcc/CGO，upx + nsis 可用

### 删除清单（清壳守业务）
- 删 `apps/desktop/src-tauri/` 整目录（Rust 源、Cargo.toml、tauri.conf.json、target/ 构建产物、icons/）—— 用 .NET `[System.IO.Directory]::Delete` 强删，**未用 takeown/icacls**（仅预案）
- 清根 `package.json`：移除 `@tauri-apps/api`、`@tauri-apps/cli`
- 清 `apps/desktop/package.json`：移除 `tauri` / `tauri:dev` / `tauri:build` 脚本与 `@tauri-apps/api` / `@tauri-apps/cli` 依赖，新增 `wails:dev` / `wails:build`
- 更新 `apps/desktop/src/main.tsx` + `vite.config.ts` 注释（Tauri → Wails）
- **守业务红线**：workbench 前端 / bridge / mcp / AgentRuntime / cli-dispatch / docs/probes/* 一行不动

### Wails 项目结构
- `apps/desktop/main.go` —— Wails 主进程，`//go:embed all:dist` 嵌入静态产物，1440×900 窗口
- `apps/desktop/app.go` —— `OnStartup` + `Greet` 占位绑定（验证 Go→JS 链路）
- `apps/desktop/go.mod` —— `module hutian-desktop`，依赖 `github.com/wailsapp/wails/v2 v2.12.0`
- `apps/desktop/wails.json` —— `frontend:dir: "./"`（关键，因 Vite 配置在 desktop 根而非 frontend/ 子目录），NSIS 中文安装包配置
- `apps/desktop/build/` —— appicon.png + windows/icon.ico + info.json + wails.exe.manifest（从 `wails init` 临时项目复制）
- `apps/desktop/src/wailsjs/` —— Wails 自动生成的 Go 绑定（App.js + runtime.js）

### 桌面版专属新坑（v2 接 bridge 前必撞必解）
- **SSE mixed-content**：Wails 自定义 scheme（`wails://` 或 `http://wails.localhost`）→ `http://127.0.0.1:4317` 的 SSE 长连接，**WebView2 可能拦混合内容**
- **欺骗性**：浏览器 dev 模式全绿，打包后 SSE 死
- **解法预案**：
  1. Wails `AssetServer` 反向代理 `/api/*` 到 `127.0.0.1:4317`（同源绕过）
  2. 或 Go binding 转发：前端调 `wailsjs/go/main/App`，Go 侧 HTTP 客户端转发到 bridge
  3. 或 bridge 启用 HTTPS（自签证书 + WebView2 信任）
- **v1 不撞**：v1 走 mock 模式，零后端依赖

### sidecar 设计（v2 占位）
- **目标**：单 exe 双击后，Go `os/exec` 起 Node bridge + Python MCP，前端 `NEXT_PUBLIC_DESKTOP=true` 时 SSE/POST 直连 `127.0.0.1:4317`
- **进程拓扑**：
  ```
  hutian-agent.exe (Wails 主进程)
    ├── child: node apps/agent-bridge/dist/server.js  (PORT=4317)
    └── child: hutian-seo-mcp (stdio MCP server, bridge 内嵌启动)
  ```
- **生命周期**：Wails `OnStartup` 起 bridge，`OnShutdown` 终止子进程；bridge 健康检查轮询 `/health` 5s 超时
- **资源**：Node runtime 需打包（nexe 或 pkg），Python MCP 需 PyInstaller 冻结
- **v1 状态**：仅 docs 占位，不阻塞 v1 出包

### env 开关分流（v2）
- `NEXT_PUBLIC_DESKTOP=true`：前端 SSE/POST 直连 `127.0.0.1:4317`（绕过 BFF）
- 否则：走 Next.js BFF `/api/sessions/*`
- **一份前端代码**：SaaS 与桌面共用，差异仅在 env
