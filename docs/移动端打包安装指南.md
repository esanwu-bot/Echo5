# 壶天移动端打包安装指南

适用于 Windows 开发机，基于 M8 Capacitor 套壳方案（`apps/mobile`）。涵盖从环境准备到生成 APK 并安装到手机的完整流程。

---

## 一、前置环境（一次性安装）

| 工具 | 用途 | 安装方式 |
|---|---|---|
| **Android Studio** | 提供 Android SDK + JDK + 模拟器/真机调试 | https://developer.android.com/studio |
| **JDK 17** | Capacitor 6 / Gradle 编译需要 | Android Studio 自带或单独装 |
| **Android SDK Platform 34+** | 编译目标 | Android Studio → SDK Manager 装 |
| **Node 18+ / pnpm** | 构建前端 SPA | 项目已配 |

装完 Android Studio 后，在 SDK Manager 里至少勾装：

- Android SDK Platform 34（或 33）
- Android SDK Build-Tools 34
- Android SDK Command-line Tools (latest)
- Android SDK Platform-Tools

> **注意**：新版 Android Studio 默认只显示 Build-Tools 最新版，找不到 34.0.0 时，请在 SDK Tools 页面右下角勾选 **Show Package Details**，列表会展开显示所有历史版本，再勾选 **34.0.0** 安装。

## 二、打包步骤

### 步骤 1：首次添加 Android 平台（只做一次）

如果 `apps/mobile/android/` 目录不存在，先添加平台：

```bat
cd e:\workspace\hutianSEOGEOAGent\hutian-seo-geo-agent\apps\mobile
pnpm build
npx cap add android
```

这会生成 `apps/mobile/android/` 原生工程目录。

### 步骤 2：构建 SPA + 同步到 Android 工程

跑现成脚本（一行搞定）：

```bat
e:\workspace\hutianSEOGEOAGent\start_mobile_android.bat
```

脚本做了三件事：

1. `pnpm build:mobile` — Vite 打 SPA 到 `apps/mobile/dist`
2. `pnpm cap:sync` — 把 dist 拷到原生工程 + 装 Capacitor 插件
3. `npx cap open android` — 打开 Android Studio 加载工程

等 Gradle sync 完成后继续下一步。

### 步骤 3：在 Android Studio 里打包 APK

#### 方式 A：Debug APK（最快，装手机测试用）

菜单栏 → **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**

等底部进度条跑完，点通知里的 **locate** 链接，APK 在：

```
apps/mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

#### 方式 B：Release APK（要装到非调试手机/上架需签名）

1. **生成签名 keystore**（只做一次）：

   ```bat
   keytool -genkey -v -keystore hutian-release.keystore -alias hutian -keyalg RSA -keysize 2048 -validity 10000
   ```

   记住密码，keystore 文件妥善保管（丢了就没法更新应用）。

2. 把 `hutian-release.keystore` 放到 `apps/mobile/android/app/` 下

3. 创建 `apps/mobile/android/key.properties`：

   ```
   storePassword=你的密码
   keyPassword=你的密码
   keyAlias=hutian
   storeFile=hutian-release.keystore
   ```

4. 编辑 `apps/mobile/android/app/build.gradle`，在 `android {}` 块顶部加：

   ```gradle
   def keystoreProperties = new Properties()
   def keystorePropertiesFile = rootProject.file('key.properties')
   if (keystorePropertiesFile.exists()) {
       keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
   }
   ```

   `signingConfigs {}` 块里加：

   ```gradle
   release {
       storeFile file(keystoreProperties['storeFile'])
       storePassword keystoreProperties['storePassword']
       keyAlias keystoreProperties['keyAlias']
       keyPassword keystoreProperties['keyPassword']
   }
   ```

   `buildTypes.release {}` 里加 `signingConfig signingConfigs.release`

5. 菜单栏 → **Build** → **Generate Signed Bundle / APK** → APK → 选上面 keystore → release → finish

输出在：

```
apps/mobile/android/app/build/outputs/apk/release/app-release.apk
```

## 三、安装到手机

### 方式 A：USB 数据线（推荐）

1. **手机开开发者选项 + USB 调试**：
   - 设置 → 关于手机 → 连点版本号 7 次 → 返回开发者选项 → 开 USB 调试

2. **USB 连电脑**，验证连接：

   ```bat
   adb devices
   ```

   应该能看到设备号

3. **装 APK**：

   ```bat
   adb install -r apps\mobile\android\app\build\outputs\apk\debug\app-debug.apk
   ```

   `-r` = 覆盖已装的同名包

### 方式 B：拷文件装（无数据线）

把 APK 文件传到手机（微信/QQ/U 盘），手机文件管理器点开 APK 安装。需先开"允许未知来源应用"（设置 → 安全 → 安装未知应用）。

### 方式 C：Android Studio 直接调试装

Android Studio 顶部设备下拉选连上的真机 → 点 ▶ Run 按钮 → 自动装并启动。这种方式能看 Logcat 日志，开发期最方便。

## 四、生产化注意事项

对齐 project_memory 红线，发布前必须核对：

| 项 | 要求 |
|---|---|
| **后端地址** | baseURL 生产值必须指向**云端 BFF**，禁止直连 bridge（localhost:4317）。dev 模式可指 `http://localhost:3000` |
| **httpOnly cookie** | Capacitor WebView 的 https origin 支持 SameSite=Strict + httpOnly cookie；写请求仍需带 `X-Hutian-Tenant` + `X-Hutian-Nonce` 头 |
| **WebView origin** | iOS 是 `capacitor://localhost`，Android 是 `https://localhost`；BFF CORS 白名单必须加入这些 origin |
| **图标/启动图** | 用 Android Studio 的 Image Asset Studio 生成（`cap add android` 后默认图标是 Capacitor logo，发布前必须换） |
| **包名** | 当前 `com.hutian.workbench`（`apps/mobile/capacitor.config.ts`），上架后不可改 |

## 五、常见坑

1. **Gradle sync 失败** — 多半是 JDK 版本不对。Capacitor 6 要 JDK 17。Android Studio → Settings → Build → Gradle → Gradle JDK 选 17

2. **白屏** — 检查 `apps/mobile/dist/` 是否生成了（Vite build 跑过没）；`cap:sync` 报错看是否 dist 为空

3. **网络请求不通** — Android 默认禁明文 HTTP。`apps/mobile/android/app/src/main/AndroidManifest.xml` 的 `<application>` 加 `android:usesCleartextTraffic="true"`（仅 dev；生产必须用 https）

4. **`cap add android` 报错 "Capacitor could not find webDir"** — 先跑 `pnpm build:mobile` 生成 dist 再 add
