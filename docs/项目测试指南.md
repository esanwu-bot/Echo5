## 4. v1.0 测试：接 grok-build（远期，Phase3）

> 此时才需要 checkout grok-build 仓库。当前**不要做**。

### 4.1 何时做

- v0.1 前端验收通过
- v0.2 本地 MCP 五工具可跑
- 需要真实 Agent 编排（用户输入 → grok 调度 → 工具执行 → 事件回流）

### 4.2 两种接入模式（技术方案 §10）

| 模式 | 做法 | 适用 |
|---|---|---|
| **A headless（推荐起步）** | bridge `spawn('grok', ['--headless','--plugin','hutian-seo'])`，解析 stdout 映射为 AgentEvent | 快速验证 |
| **B ACP** | bridge 作 ACP client 嵌入 grok，结构化拿事件 | 生产级 |

### 4.3 大致步骤（届时再细化）

1. 按官方文档安装 grok-build（不 fork，只装运行时）
2. `hutian-seo-plugin` 通过 `.grok-plugin/plugin.json` + `.mcp.json` 注册为插件
3. bridge 用模式 A spawn grok，把工具调用边界映射为 `tool_start/tool_end`、文件编辑映射为 `diff`、终端输出映射为 `terminal`
4. web 端把 `useAgentSession` 的 `mode` 从 `"mock"` 切到 `"sse"`，连接真实 bridge session
5. 验收：用户输入一句话 → 真实工具执行 → 事件流驱动 UI

## 5. 常见问题

### Q1: `/workbench` 白屏？

- 查终端是否有 TypeScript 报错
- 查浏览器 Console
- 确认 `next-env.d.ts` 存在（已修复过一次）

### Q2: mock 时间线不播？

- `useAgentSession("mock")` 的 `startMock` 在 mount 后 600ms 触发
- 查 `demo-events.ts` 是否完整（应 30 条事件）
- 刷新页面重试

### Q3: 主题切换后官网配色变了？

- 不应该。官网用 `.mkt` 作用域 + `--mkt-*` 固定品牌色，工作台用全局 `--bg0/--text` 变量
- 若变色，查 `(marketing)/layout.tsx` 的 `MARKETING_CSS` 是否被工作台类名污染

### Q4: bridge SSE 连不上？

- 确认 bridge 在 4317：`curl http://localhost:4317/sessions -X POST`
- web 端 `mode="sse"` 时走 `/api/sessions/[id]/stream` BFF 代理，查 `apps/web/app/api/sessions/[id]/stream/route.ts`
- `BRIDGE_URL` 环境变量是否正确

### Q5: 中文乱码？

- 所有含中文文件必须 UTF-8（无 BOM）
- 曾出现 `plugin.json` / `LICENSE` 被 GBK 误存为 "澹跺ぉ"，已修复
- 若再现，用编辑器另存为 UTF-8 重新提交

### Q6: `tsc` 报 `unknown` 不能赋给 `ReactNode`？

- JSX `&&` 链中遇到 `unknown` 类型值，用 `!!value` 转布尔
- 已在 `ToolCall.tsx` 修复过
